# Bruce Arsenal 1.16.1 and BLE Stability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Update Bruce Arsenal to Bruce 1.16.1 and fix BLE discovery/exit stability on the LilyGo T-Embed CC1101 without adding new victim-targeted or disruptive attack behavior.

**Architecture:** Merge upstream 1.16.1 in a dedicated branch, preserve Arsenal-only files, and resolve shared files toward upstream lifecycle fixes plus concrete Arsenal hooks. Keep BLE scan ownership in `src/modules/ble/ble_common.cpp`, with one static callback, bounded result conversion, and one idempotent cleanup path.

**Tech Stack:** Arduino C++, ESP32-S3, PlatformIO 6.1.19, Arduino-ESP32 3.3.6, NimBLE-Arduino 2.5.1, GitHub Actions, esptool.

## Global Constraints

- Upstream baseline: `pr3y/Bruce` tag `1.16.1`.
- Target environment: `lilygo-t-embed-cc1101`.
- Preserve Arsenal modules and existing board environments.
- Bound BLE menu storage with `MAX_DISPLAY_DEVICES`.
- Stop and clear BLE scans before deinitialization.
- Do not add MAC impersonation, evil-twin credential capture, WPS exploitation, hidden-network disclosure, BLE disruption, or other new offensive actions.
- Add regression coverage or a documented hardware check for every ESP32-only behavior change.
